# AuditChain Ledger v3.0.0 — Enterprise Multi-Tenant Platform

Privacy-preserving compliance with Zero-Knowledge Range Proofs and multi-tenant isolation.

## Features
- Pedersen commitments + bit-decomposition ZK Range Proofs
- Cryptographically isolated tenant partitions
- HMAC non-repudiation signatures
- Designed for SOX / HIPAA / GDPR style audit trails
